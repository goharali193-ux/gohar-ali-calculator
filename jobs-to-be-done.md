# Jobs To Be Done

Each job describes what the person needs to get done, whether or not this app exists. Jobs do not mention the app, buttons or screens.

---

**J-1 (Project Manager)**
When a contract is signed and I need to plan billing, I want to know how much is payable at each stage of the project, so I can tell my team and the client what to expect and plan cash flow.

**J-2 (Project Manager)**
When the delivery plan or scope changes, I want to see how a different payment split changes the amounts, so I can agree a revised schedule with the client before announcing it.

**J-3 (Finance Analyst)**
When a milestone is completed and I am asked to raise an invoice, I want to confirm the exact amount due, so I can issue a correct invoice without going back and forth with the project team.

**J-4 (Finance Analyst)**
When I record or review a payment schedule against a contract, I want to confirm that all payments add up to the full contract value, so I can be sure nothing is under-billed or over-billed.

**J-5 (Sales Manager)**
When I am negotiating payment terms with a client, I want to compare alternative splits quickly, so I can propose terms that work for both sides before the contract is finalised.
